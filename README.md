# Harder Kanto (Gen1Recomp)

Difficulty mods for Pokemon Red, Blue, and Yellow in Gen1Recomp. Trainers play their good moves, bosses have coverage, and EXP is a slider. No new species, no held items, no Exp. Share.

Install each folder into Gen1Recomp `mods/`, or import a zip of that folder. Enable the ones you want. Options live on the mod page in the mod manager (F10), not the game OPTIONS menu.

## Mods

| Folder | What it does |
|---|---|
| `rr_style_ai` | Trainer AI. KO checks use the Gen 1 minimum roll, so a roll-dependent KO is not treated as free. Anti-setup, Wrap, Disable, Haze, smart leads, on-faint send-ins. Wild battles stay vanilla. |
| `rr_boss_teams` | Gyms, Giovanni, rivals, Elite Four. Brock and Misty stay three mons. Later gyms get a coverage mon or move so the gym type is not a free sweep. |
| `rr_sub_bosses` | Three story chokepoints: Viridian Forest Bug Catcher, Nugget Bridge Rocket, Pokemon Tower 7F Rockets. |
| `xp_rate` | Battle EXP from 0.50x to 2.00x in 0.25 steps. Does not add a share. Also works on Gen 2 if that hook is live. |

`rr_style_ai` plus `rr_boss_teams` is the intended pair. Sub-bosses and XP rate are optional.

## Difficulty

- Early game stays small. Brock has no Earthquake Onix. Misty has no Thunder Wave.
- The type on the gym door still beats most of that gym. One mon or one move punishes the obvious lead.
- Sabrina is the shared wall. Giovanni's Rocket fights are real bosses. Tower 7F is three fights with no heal between them.
- Default AI is Full + Brutal on gyms, Elite Four, Giovanni, and rivals.

## Notes

Mod ids are unchanged (`rr_style_ai`, `rr_boss_teams`, `rr_sub_bosses`, `xp_rate`) so an existing install keeps its options. Display names are the "Harder ..." titles.
